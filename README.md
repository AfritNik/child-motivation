# Семейная система мотивации — MVP

Мобильное семейное приложение для учёбы, самостоятельности, обменных баллов и наград. MVP реализован поэтапно и готовится к семейному пилоту.

## Что за что отвечает

- `src/app` — страницы и оформление Next.js;
- `src/lib/domain` — правила приложения, не зависящие от экрана и базы;
- `prisma/schema.prisma` — понятное описание таблиц PostgreSQL;
- `prisma/migrations` — последовательные изменения базы в обычном SQL;
- `prisma/seed.ts` — начальные данные для разработки;
- файлы `*.test.ts` — быстрые проверки правил через Vitest.

В стартовых данных есть Саша, Папа, Дедушка, четыре четверти 2026/2027 и три приоритетных предмета. У предмета хранится только последнее актуальное среднее за текущую четверть; история вводов не ведётся. До 1 сентября 2026 года в production намеренно добавлена отдельная тестовая четверть для семейной проверки системы.

## Реализовано в MVP

- персональный вход по PIN и роли ребёнка, администратора и взрослого;
- ежедневные отметки с подтверждением взрослого;
- домашние дела, новый продукт и журнал баллов;
- каталог и выдача наград;
- текущие средние за четверть и недельный режим;
- просмотр просроченных дней и компенсирующие исправления;
- PWA, production-контейнеры и подготовка к Yandex Cloud.

## Основные команды

- `npm run dev` — запустить приложение для разработки;
- `npm run test` — проверить правила;
- `npm run test:integration` — проверить транзакции и конкурентные сценарии в одноразовой изолированной PostgreSQL;
- `npm run test:e2e` — пройти ключевой сценарий ребёнка и взрослых в Chromium на одноразовой базе;
- `npm run build` — проверить производственную сборку;
- `npm run db:migrate` — применить изменения структуры базы;
- `npm run db:seed` — записать начальные данные.

Инструкция по размещению находится в [`deploy/README.md`](deploy/README.md). Секреты и настоящие PIN никогда не добавляются в Git.

## Безопасность тестов с базой

Интеграционные и браузерные проверки не используют `DATABASE_URL` разработчика. Скрипт создаёт временный кластер PostgreSQL на случайном порту (никогда не `5432`), применяет миграции к новой базе `family_motivation_integration` и удаляет весь временный каталог после завершения — в том числе при падении теста. Для запуска нужен локальный PostgreSQL 17 (`initdb`, `pg_ctl`, `createdb`). Браузерная проверка также требует установленный Chromium Playwright (`npx playwright install chromium`).

Контролируемые PIN тестового seed: `5555` — ребёнок, `0000` — администратор, `1111` — взрослый. Эти значения предназначены только для локального изолированного стенда.
